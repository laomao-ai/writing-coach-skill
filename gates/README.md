# 五关：立意 → 结构 → 证据 → 语言 → 读者

一篇稿子按顺序过五关。前一关没过，后一关的分数参考意义有限：立意不清的稿子，句子再顺也只是顺。

每关 0–4 分，满分 20。打分只看稿子本身，**每个分数必须附一句原文依据**；说不出依据就不打分，写“无法判断”。

| 关 | 问的是 | 主要检查 | 常请的大师 |
|---|---|---|---|
| ① 立意 | 写什么、为谁写、读完相信什么 | 一句话主题、读者、承诺与兑现 | 刘勰、金瑟、戈德堡、朱光潜 |
| ② 结构 | 先说什么、怎么分组、怎么推进 | 结论先行、MECE、SCQA、冲突 | 明托、高杉尚孝、麦基 |
| ③ 证据 | 每个论点凭什么成立 | 论据对应、事实核查、引语出处 | 阿伦斯、事实清单 |
| ④ 语言 | 读起来顺不顺、像不像这个作者 | 具体、简洁、AI 味、错别字 | 鲁迅、叶圣陶、汪曾祺、平克、金、斯特伦克、奥威尔 |
| ⑤ 读者（传播） | 读者为什么点开、读完、转给别人 | 开头钩子、信息密度、记得住的一句、行动落点 | 希思兄弟、麦基、叶圣陶 |

传播只看“读者愿不愿意读完、记不记得住”，**不鼓励标题党、制造焦虑、追热点**；建议夸张标题的，读者关不加分。

写作习惯（每日定量、先写烂初稿、限时写）不进评分：一篇稿子看不出习惯。习惯类大师（拉莫特、戈德堡、金）只在引导写里用。

## 评分锚点

### ① 立意
- 4：能用一句话复述主题，读者明确，结尾兑现了开头的承诺。
- 3：主题清楚，但有一段偏离主题或结尾没完全兑现。
- 2：能猜出主题，需要读完全文才知道；读者不明确。
- 1：有两个以上互相竞争的主题。
- 0：说不出这篇要读者相信什么。

### ② 结构
- 4：结论先行或有意设悬念且最终回收；同级要点不重不漏；每段都推进主题。
- 3：整体清楚，个别分组混类或顺序可调。
- 2：要点能找到，但顺序随意，有重复或跳步。
- 1：段落之间看不出关系。
- 0：无结构，像随手记录。

### ③ 证据
- 4：每个关键论点都有对应论据；可验证断言都有出处或明确是个人经历；无疑似虚构引语。
- 3：有 1 处关键断言缺出处。
- 2：有 2 处以上缺出处，或有论据与论点不对应（相关当因果等）。
- 1：主要论点只有断言没有论据。
- 0：有虚构或明显错误的事实、数据、引语且是论证的支点。

### ④ 语言（只评“顺不顺、具体不具体”，不评“像不像某种文风”）
- 4：具体、简洁、节奏自然；保有作者自己的声音；无错别字。
- 3：少量空话或赘词，不影响阅读。
- 2：多处套话、空洞升华或形容词堆砌；或有错别字。
- 1：大段内容可以套进任何文章。
- 0：读不下去。

### ⑤ 读者
- 4：开头 3 句内让读者知道“和我有关”；信息密度高；读完知道下一步做什么或换了什么看法。
- 3：开头稍慢或结尾落点偏虚。
- 2：读者要读到一半才知道为什么要读。
- 1：只写作者想说的，没考虑读者。
- 0：读者无法从中得到任何东西。

## 第 ⑥ 关：对抗（给 skill 用，不给作者打分）
skill 本身要过的一关：被诱导编造、改立场、洗稿、一键成文时守不守得住。见 evals/。

## 使用约定
- 总分只是摘要，**报告的价值在问题清单**。不要为了凑分而挑毛病，也不要因为分高就省略“没问题的部分”。
- 作者明确只要某几关时，只评那几关。
- 同一篇稿子改前改后都打分，才能看出改进；分数变化要能对应到改动清单里的具体改动。
