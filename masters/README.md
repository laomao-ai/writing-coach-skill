# 大师团：请的是方法，不是本人

每位大师一张卡。卡上只放能回到原书核对的主张，用自己的话转述，不摘录原文。

## 入选标准
五道门槛，缺一不收：
1. **顶尖**：在写作或写作教学上公认有分量。
2. **有知名度**：一说名字，普通读者大多知道是谁。
3. **有专门讲写作的代表作品**：书或名篇都算；畅销小说本身不算。
4. **能真正指导写作**：主张能转成可检查的问题。
5. **对中文写作适用**：只适用于英语语法的不收。

打分：知名度、写作代表作、指导力、中文适用，各 0–3 分。前两项低于 2 分直接不收，总分 ≥9 才收。和作者无关的通用框架（金字塔原理、SCQA、SUCCESs 等）不算大师，放进 [methods/](../methods/README.md)；练习方法放进 [drills/](../drills/README.md)。

## 文体路由：先认文体，再请人
一篇稿子最多请 **3 位**。余光中做全局语言检查，每类都过一遍，不占名额。作者点名要谁，就按作者的来；判断不了文体时用“通用”。

**题材和写法冲突时，按写法判**：例如“本地跑大模型踩的三个坑”，题材是科技，写法是第一人称复盘，按“经验复盘”请人。报告里写一句“题材偏××，按写法判为××”，让作者知道可以改判。

|---|---|---|

| 干货教程 | 津瑟、叶圣陶、平克 | pyramid、feynman |

| 科技科普（含资讯） | 平克、津瑟、叶圣陶 | feynman、inverted-pyramid、williams |
| 测评体验 | 津瑟、叶圣陶、奥威尔 | scqa、inverted-pyramid |
| 经验复盘 / 个人成长 | 斯蒂芬·金、叶圣陶、津瑟 | pyramid |
| 故事人物（非虚构） | 斯蒂芬·金、麦基、汪曾祺 | iceberg |
| 随笔散文（含情感） | 汪曾祺、朱光潜、老舍 | iceberg |
| 文化读书 | 刘勰、朱光潜、夏丏尊 | zettelkasten |

每类的检查侧重：
- 测评体验：亲测细节 vs 官方通稿；有没有写清测试条件和缺点。
- 经验复盘：故事有没有落到读者能用的结论。
- 随笔散文：真诚还是煽情（见 gates/README.md 读者关）。
- 观点评论：有没有正面回应最强的反方。

## 用法
- 体检：报告开头写明“文体：××”，各关引用的大师只从这一类的名单里选。
- 会诊：见 modes/consult.md。
- 写前拷问：见 modes/guide.md 第 1 步，由该文体名单里管立意的大师轮流追问。
- 大师只**提问和挑问题**，不改写；不模仿大师口吻，不写“斯蒂芬·金会说……”这类冒用其名义的话，改用“按金的‘删副词’原则，这一句……”。

## 卡片格式（新增大师请照此写）
```
# 大师名 · 代表作品
来源：书名/篇名（作者，原版年份）；中文版：译者/出版社（待补则写“待补”）
主管关：……
适用文体：……（以上面的路由表为准）
## 核心主张（3 条以内，自述转述）
## 会问你的问题（3 个，用于会诊）
## 能查出的问题（对应体检项）
## 不适用 / 局限
## 核对状态：篇名或章节已核 / 待核
```
**可溯源规则**：卡里写到的篇名、章节名、概念名必须能在原书找到。核到篇名或章节即算“已核”，不要求页码；没核对过的标“待核”，不许凭记忆写页码，不许加引号冒充原文。
