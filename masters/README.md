# 大师团：请的是方法，不是本人

每位大师一张卡。卡上只放能回到原书核对的主张，用自己的话转述，不摘录原文。

## 用法
- 体检时，每一关默认请 1–2 位大师（见 gates/README.md 的“常请的大师”）。
- 会诊时，作者点名，例如“请明托和金看看”。没点名就按稿子的毛病推荐 3 位，每位挑 1 条最要紧的问题，并说明为什么请他。
- 大师只**提问和挑问题**，不改写；不模仿大师口吻，不写“斯蒂芬·金会说……”这类冒用其名义的话，改用“按金的‘删副词’原则，这一句……”。

## 候选（未核对，不进会诊）
奥格威《一个广告人的自白》（标题与读者，需防标题党化）、乔纳·伯杰《疯传》（传播）、费曼（“费曼学习法”不是费曼本人著作里的提法，暂不收）。核对完原书、按下面格式写好卡片后再加入。

## 卡片格式（新增大师请照此写）
```
# 大师名 · 书名
来源：书名（作者，原版年份）；中文版：译者/出版社（待补则写“待补”）
主管关：……
## 核心主张（3 条以内，自述转述）
## 会问你的问题（3 个，用于会诊）
## 能查出的问题（对应体检项）
## 不适用 / 局限
## 核对状态：章节定位已核 / 待核
```
**可溯源规则**：卡里写到的篇名、章节名、概念名必须能在原书找到；没核对过的标“待核”，不许凭记忆写页码，不许加引号冒充原文。
