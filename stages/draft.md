# ③ 成稿

目标：写出一篇能发的完整稿子，五关都顾到。

## 起点不限
| 用户给了什么 | 怎么写 |
|---|---|
| 只有题目或一个想法 | 先在心里过一遍 ① 和 ②（立意 + 提纲），给用户看一眼提纲再写；用户说“直接写”就直接写 |
| 标题 + 几个观点 | 按观点搭提纲，直接成稿 |
| 卡片、笔记、素材 | 以素材为骨，按文体选结构成稿 |
| 半成品草稿 | 顺着已写的部分续写，口吻和已写部分保持一致 |
| 提纲（来自 ②） | 按提纲逐节写 |

## 写法
1. **认文体，请对口的大师**：成稿时大师的方法是写作守则，不是腔调。例如叶圣陶“写话即说话”、津瑟“删繁就简”、平克“想象一个聪明的外行读者”、斯蒂芬·金“少用副词、写真实细节”、汪曾祺“语言就是内容”。
2. **按场景卡写**（默认公众号，见 library/wechat.md）：段落长度、小标题、开头结尾的习惯。
3. **有风格档案就按档案写**（stages/polish.md 末尾）；用户给了旧文章，先从中提炼 3–5 条风格要点再写。
4. **证据**：用户给了的材料优先用；需要数据、案例、引语但手上没有的，写成【待核实：需要什么】，不要把拿不准的东西当事实写进去。
5. **篇幅**跟着内容走，不注水。

## 交付
1. 全文（可直接排版）
2. 待核实清单：每条写清需要什么、去哪找（没有就写“无”）
3. 一行自评：结论 + 短板，例如“改完再发 · 短板：证据（两处待核实）”

用户想要更严的检查，进 ④ 体检；想改得更顺，进 ⑤ 打磨。
