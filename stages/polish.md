# ⑤ 打磨

目标：把稿子改得更好读，分数往上走。

## 强度
- 轻：只改错字、赘词、标点。
- 中（默认）：删空话、换具体、调节奏，可以删整句。
- 重：重组段落、改结构、改开头结尾。

## 方向
- **保留原风格**（用户说“保留我的风格”或有风格档案）：只动有问题的地方，用户的口头表达、立场、确定程度不动。
- **按文体或大师的要求改**：例如“按奥威尔删一遍”“按倒金字塔重排”“改成更适合公众号的节奏”。按所请大师卡和方法卡上的主张改，不模仿大师本人的文风。
- **去 AI 腔 + 注入个人风格**：按 library/ai-tone.md 先查后改：先补具体，再删空话，最后调节奏；再按风格档案把口吻改回作者自己的。没有档案时请作者给两三篇旧文，现场提炼 3–5 条。
- **按平台改**：按场景卡的侧重调整（公众号见 library/wechat.md）。

## 流程
1. 先快速过一遍五关，有 P0（事实错误、论证支点不成立）先单独告诉用户。
2. 逐句处理：删空话 → 换具体 → 调节奏。没问题的句子不动。
3. 正文保持干净，不在正文里插标注；待核实的事项放在清单里。

## 输出
改后全文 + 改动清单（原句 → 新句 → 原因）+ 可选的改前 / 改后五关对比（分数变化对应到具体改动）。

## 风格档案（可选）

想让写出来、改出来的稿子更像你，就建一份风格档案。成稿和打磨都会读它。

### 怎么建
给 2–3 篇你满意的旧文章，或者直接描述。提炼成下面几项，存成 style-你的名字.md 放在项目里，或直接贴在对话开头：

```
# 风格档案：作者名
- 人称与身份：我 / 我们；以什么身份说话
- 句子：长短、节奏、爱不爱用短句收尾
- 口头表达：常用的词、说法（照原样记）
- 语气：确定程度（“我觉得”“可能”怎么用）、幽默程度
- 结构习惯：开头怎么起、结尾怎么收、小标题风格
- 不要：你讨厌的写法
```

### 怎么用
- 成稿：按档案写；档案和文体习惯冲突时，以档案为准。
- 打磨：档案里记下的口头表达和语气不改。
- 档案只记风格，不记观点；每篇的观点以当篇为准。
