# ④ 体检

目标：用五关给稿子打分，指出每个问题在哪、怎么改。

## 先说结论：给人看的三行
报告开头固定三行，普通读者看这三行就够：

```
结论：✅ 可以发 / 🟡 改完再发 / 🔴 先别发
短板：哪一关 + 原文里的哪一处（一句话）
先改：最该先动的一件事（一句话）
```

| 结论 | 条件 |
|---|---|
| ✅ 可以发 | 五关都 ≥3 分，没有 P0 |
| 🟡 改完再发 | 有一关 2 分，或有需要处理的 P1 |
| 🔴 先别发 | 有阻断项（P0：事实错误、虚构引语、论证支点不成立），或有一关 ≤1 分 |

五关在报告里画成 4 格条（▰▰▰▱），不在正文里写“17/20”这样的总分：差一两分对读者没有意义，结论和短板才有。总分只出现在评分块里，给别的 Agent 和流水线比较改前改后用。

## 怎么查
第一步先判断文体（masters/README.md 路由表），报告开头写明“文体：××”；然后按五关过一遍（评分锚点见 library/gates.md）：

| 关 | 检查清单 | 方法卡（library/methods.md） |
|---|---|---|
| ① 立意 | library/checks.md 逻辑第 1 组 | feynman、zettelkasten |
| ② 结构 | library/checks.md 逻辑第 2 组 | pyramid、scqa、inverted-pyramid |
| ③ 证据 | library/checks.md 事实核查 | 观点评论用 harvard |
| ④ 语言 | library/ai-tone.md（AI 腔单列一行）、library/checks.md 错别字 | 全局：余光中卡；按文体：williams、iceberg |
| ⑤ 读者 | library/checks.md 逻辑第 3 组 | success |

每关引用的大师只从该文体的名单里选。体检结束时，针对得分最低的一关，从 library/drills.md 推荐一个练法。

## 规则
1. **每个问题带原文定位**（段落 + 原句，不超过 30 字）和改法。
2. **严重度**：P0 = 事实错误、论证支点不成立；P1 = 证据缺失、论证薄弱、错别字；P2 = 语言、节奏、措辞。
3. **事实状态**：已核实（给出处）/ 待核实（写清缺什么）/ 疑似错误（写出依据）。没有联网检索时，依据又不在稿子内部，最多写到“待核实”。个人经历不要求外部出处。
4. **稿子已经好就直说**：P0 写“无”，把篇幅留给“写得好的部分”。分数严格按 library/gates.md 的锚点给，满足 4 分锚点就给 4，不因为还能挑出 P2 小问题就扣分。
5. 用户只要看某几关，只详评那几关。
6. 作者声明有个人风格时，语言关只提示，不建议改写。

## 报告格式
```
结论：🟡 改完再发
短板：证据 · 第 3 节「越往下越难一键」只有判断，没有一个自己的例子
先改：补一个亲身经历的例子

文体：观点评论（请：胡适、鲁迅、奥威尔）
立意 ▰▰▰▰  结构 ▰▰▰▰  证据 ▰▰▱▱  语言 ▰▰▰▱  读者 ▰▰▰▰

阻断项（P0）：无
要改（P1）：[段落]「原文 ≤30 字」→ 问题 → 改法
可改（P2）：[段落]「原文」→ 信号 → 可选做法（作者有个人风格时只提示）
AI 腔：命中 N 处，最典型两处 + 改法（没有写“无”）
写得好的地方：至少两条，指回原文
下一步练什么：按最弱一关从练法库选一个
```
待补证据多时，附一张表：断言 / 需要什么证据 / 建议检索。

## 请大师会诊
用户说“请大师看看”或点名某几位：按路由表请这一类的大师（最多 3 位，各一句话说明为什么请他），点名的照请。每位大师从卡上“会问你的问题”和“能查出的问题”出发，挑最多 3 条，每条：原文定位 → 依据哪条主张 → 改法或追问。大师之间意见冲突时摆出来，说明各自适合什么情况。结尾给 3 条按优先级排的处方。格式：
```
会诊名单：大师 A（为什么请他）、大师 B……
大师 A · 主管关
1. [段落]「原文」→ 依据卡上哪条主张 → 问题；追问：留给作者的一个问题
意见冲突（如有）：问题 / A 的看法 / B 的看法 / 各适合什么情况
处方：作者自己动手的 3 件事，按优先级
```卡里没有的主张不替大师发挥，不写“某某会说……”。

## 只核事实
用户只要查数字和引语：跳过评分，逐条列出数字、日期、人名机构、引语、研究结论及位置，标状态，附检索建议。

## 评分块（给别的 Agent 读）
用户或上游流程要机器可读的结果时，在报告末尾附（verdict 取“可以发 / 改完再发 / 先别发”）：

```json

```
