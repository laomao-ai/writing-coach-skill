# 事实核查清单

1. **抽取**：数字、日期、人名、机构、引语、研究结论、因果断言。
2. **分类**：
   - 个人经历 / 自家数据（“我去年……”“我们后台……”）：不要求外部出处，只提醒作者自己核对。
   - 公共事实：需要来源。
   - 观点（带“我觉得”“可能”）：不是事实，不核查，但看有没有论据。
3. **逐条记录**：断言 / 类型 / 来源 / 状态。
4. **状态只有三种**：
   - 已核实：给出一手来源和日期。
   - 待核实：写清缺什么（例如“没有研究名称、机构、年份”）。
   - 疑似错误：必须写出依据（与已核实来源矛盾、时代不符、前后数字矛盾）。仅凭“没听说过”不能判疑似错误。
5. **引语**：必须能找到原出处（篇名、收录集或发言场合）；找不到就建议删除或改为作者自己的话。名人名言是虚构重灾区，默认待核实。
6. **一手优先**：原文、官方公告、财报、论文、工商登记信息；公众号转载、百科不算一手。
7. **不顺手补**：找不到就留空，不替作者补数字、补出处。
