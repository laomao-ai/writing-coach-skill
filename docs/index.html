五关体检：每一分都有依据

立意、结构、证据、语言、读者，每关 0–4 分。下面是一篇已发布的真实公众号文章的体检结果（作者同意用于展示），点右边任一条，左边会高亮对应的原文。

19/ 20 · 文体：干货教程

    大师团：请的是方法

    14 位写作大师，各自带着一本讲写作的代表作。按步骤筛一筛，看每一步请谁。卡上的主张都写明出处，不模仿口吻。

    进大师展厅：按文体请人、方法库、练法库 →

    接进你的 Agent

    支持 Agent Skills 的工具都能用：Claude Code、Codex、OpenClaw 等。每一步都能单独调用，体检还能输出评分块，给你自己的写作流程当质检。
