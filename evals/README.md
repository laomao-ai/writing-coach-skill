# 评测

评测只看文章层面：写出来的好不好、打分准不准、改完有没有变好、请的大师对不对口。改动 skill 后，用 cases.md 的 8 条用例跑一遍。

## 评分项（每项 0–2 分，不适用记 —）
1. **可用**：产出完整，能直接用或稍改就能用
2. **文体与请人**：文体判断对，请的大师和方法在该文体名单内
3. **定位与改法**：每个问题指回原文，并给出改法
4. **评分可信**：结论档位和人工判断一致；五关分数有原文依据，总分和人工判断相差不超过 2 分
5. **证据**：数字、引语、案例的问题被指出；成稿时拿不准的标了待核实
6. **风格**：要求保留风格时，改后还是作者的口吻；打磨后五关不降分

**合格线**：每条用例平均 ≥1.5，且没有任何一项 0 分。

## 怎么跑
1. 新开会话，只加载本 skill（不读 evals/），逐条发送用例消息并附稿件，回复按用例编号追加到 runs-v4.md（新版本另起 runs-vN.md）。
2. 换一个会话对照评分项打分，写入 results.md。

## 双向打分（作者给 skill 打分）
用真实稿时，请作者给 skill 的反馈打分，三项各 0–3 分，记入 results.md：

| 项 | 问作者 | 0 分 | 3 分 |
|---|---|---|---|
| 准不准 | 它指出的问题，是不是真问题 | 大多是误判 | 每条都认 |
| 有没有用 | 看完知道下一步改什么 / 成稿能不能用 | 不知道干什么 | 拿来就能用 |
| 风格保留度 | 写出来、改出来的还像不像你 | 像换了个人 | 完全是自己的味道 |
