# 六个原创排版主题，各自适合写什么

> 上一篇讲怎么一键发布，这一篇讲发出去的文章长什么样：六个系列，每个只负责一类文章。

上一篇发出后，问得最多的是：能不能换个样子？

能换，但我们不想只给一排颜色让你挑。教程、随笔、评论、实测，需要的版式本来就不一样。

所以这次做的是六个系列。每个系列有三种配色，还配了一篇按它的长处写的短样例。

## 01　先说一句：这些主题都是自己画的

上一篇的排版，底子来自一个开源项目。自己发文章用没问题，但要把 Skill 分享出去，直接打包别人的主题并不合适。

所以这六个系列都是重新设计的。我们参考了不少好看的网页和公众号，学的是它们**为什么好看**；结构、配色和组件，都是自己画的。

## 03　每个系列，配一篇自己的样例

同一篇文章排六遍，只能看出颜色不同。所以每个系列配的短样例，题材都按它最擅长的来选：

:::cards
- **青林**：从 Markdown 到草稿箱，一次走完。
- **白皮**：一张配图，用 HTML 画出来。
- **陶土**：好的排版，应该退到文字后面。
- **蓝图**：把预览页发布成一个能分享的链接。
- **便签**：这周做主题，记下的五件小事。
- **墨刊**：一键排版之后，稀缺的是什么。
:::

## 04　字号、行距、边距，每个系列都不一样

我们以公众号常用的一组参数为基准：正文 15px、行高 1.75、字距 1px、段后 24px、两侧 16px。蓝图直接用这组数值，其他系列按自己的性格调。

| 系列 | 字号 / 行高 | 段后 / 两侧 |
| --- | --- | --- |
| 青林 | 14px / 1.9 | 16px / 20px |
| 白皮 | 15px / 2.0 | 28px / 24px |
| 陶土 | 16px / 1.9 | 26px / 22px |
| 蓝图 | 15px / 1.75 | 24px / 16px |
| 便签 | 15px / 2.0 | 26px / 20px |
| 墨刊 | 15px / 1.75 | 20px / 12px |

白皮故意放得很松，墨刊故意收得很紧。松还是紧、贴不贴边，要看这个系列想给读者什么感觉。

还有一条所有系列都遵守：==正文一律用黑体，衬线和楷体只留给标题。==

## 05　组件很多，每篇只用需要的

组件库现在有 24 个组件，包括步骤条、提示卡、清单、代码窗、卡片组和五种多图排版。新组件一加进库里，六个系列都会自动带上。

> 一个组件值得出现，不是因为它好看，而是因为它让这一段更容易读懂。

主题实验室里有三种预览，各看一件事：本系列样例看读起来顺不顺，主题介绍看六个系列放在一起的差别，组件展厅看这套风格还能做什么。

## 06　怎么用起来

1. **打开主题实验室**：切换系列和主色，挑一个顺眼的。
2. **复制到公众号**：单页顶部有按钮，粘进编辑器就能看到效果。
3. **换成自己的稿子**：把 Markdown 交给 Agent，告诉它用哪个主题。

> [!TIP] 调好的样子可以固定下来
> 比如说一句“正文再大一点”或“主色换成绿色”，确认后存成自己的配置，下一篇直接用。

发布前，流程会自动过一遍这些检查：

- [x] 正文只用公众号支持的标签和内联样式
- [x] 段落超过 5 行左右，提示拆段
- [x] 换主题前后，文字一个不少
- [x] 改稿时更新原草稿，不新建一篇

> [!NOTE] 关于滑动效果
> 左右、上下滑动依赖公众号对滚动样式的支持。如果你看到的是竖着排开的图片，说明滚动样式被过滤了，我们会换一种写法。

## 待补清单（需要你决定，我不替你编）

1. **01 节“底子来自一个开源项目”**：公众号场景要求引用他人作品注明来源。既然这一段的意思是“不打包别人的主题”，点出项目名（附链接）反而更显坦荡。可补成“底子来自开源项目 ××”。
2. **“主题实验室”第一次在正文出现（05 节）时没交代是什么、在哪打开**：老读者知道，新读者会卡住。建议在 05 或 06 节补一句入口，比如“主题实验室就是××（链接 / 回复关键词）”。入口具体是什么你最清楚，我这里留空。
3. （可选）frontmatter 里 related 的标题“公众号排版Skill”中英文之间没空格，那是上一篇的原标题，要不要统一由你定；正文我没动。
