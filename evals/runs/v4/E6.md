# E6 · 体检（真实稿）

**稿件**：《六个原创排版主题，各自适合写什么》
**文体：科技科普（含资讯）**。题材偏工具更新，写法是“产品介绍 + 使用说明”，按写法判为科技资讯类；如果你更想把它当干货教程看，可以改判，请的大师基本不变。
**本次请的大师**：平克（读者、术语）、津瑟（一篇只做一件事、删杂物）、叶圣陶（念得顺、像说话）；余光中卡做全局语言检查。
**场景**：微信公众号长文。
**定位方式**：§ 表示小标题编号（导语记为“开头”），“第 N 段”按该小节内的段落顺序数。

---

**总评**：最强的一点是“按文章类型选，不按颜色选”这条主线立得住，表格、参数、样例都是自家一手材料，句子短、干净、有自己的声音。最需要先改的一点是读者落点：读完想动手的人找不到“主题实验室”在哪儿，几个内部叫法（头部IP、组件展厅、单页、Agent）也没解释。

## P1 建议改（证据缺失、论证薄弱、错别字）
- [§06 第1条]「打开主题实验室：切换系列和主色」→ 读者不知道主题实验室在哪儿、怎么打开（知识的诅咒：作者天天用，默认读者也知道）→ 补一个入口：链接、“阅读原文”、仓库里的文件路径，或对 Agent 说的那句指令。这是全文最该补的一处。
- [§01 第1段]「底子来自一个开源项目」→ 没写项目名。公众号场景卡要求引用他人作品注明来源，而且这一段的重点正是“尊重别人的主题”，点名致谢更能说明态度 → 写出项目名和链接，例如「底子来自开源项目 ××（链接）」。
- [§04 第1段]「以公众号常用的一组参数为基准：正文 15px、行高 1.75……」→ “常用”是公共断言，状态：**待核实**，缺“常用”的依据（统计、平台默认值，还是作者的经验）→ 有出处就补；没有就改成作者自己的判断，例如「我们以一组公众号上很常见的参数为基准」或「以我们看过的几十个号的常见参数为基准」（数字请按实际填）。
- [§02 表格]「白皮 · 头部IP」「一眼认出它：横滑目录、PART 章节头」→ “头部IP”是行业黑话，和右边“AI 工具实测、产品速览”对不上，读者猜不出为什么叫这个 → 一句话解释，或换成读者一看就懂的名字（只提示，系列名是作者的品牌决定）。
- [§05 第3段]「本系列样例……主题介绍……组件展厅」、[§06 第2条]「单页顶部有按钮」、[§06 第3条]「把 Markdown 交给 Agent」→ 三个预览名、“单页”“Agent”都是第一次出现，没解释 → 第一次出现时各加半句，例如“组件展厅（把所有组件排在一页的预览）”“Agent（你在用的 AI 写作助手）”。
- [§02 表格 ↔ §03]「适合写什么」→ 标题承诺的是“各自适合写什么”，正文只在表格一格里带过，没说**为什么**墨刊适合热点、陶土适合随笔；§04 结尾「要看这个系列想给读者什么感觉」也只点到为止 → 在 §03 每张卡片后补半句理由即可，例如“墨刊：刊头粗、段距紧，读起来快，适合要赶时间看的热点”（示范，请按你的设计意图改写）。

## P2 可选（语言、节奏、措辞；只提示）
- [开头第3段 / §01第2段 / §03第1段 / §05第3段] 四段都以「所以」开头 → 相邻段同一骨架；其中 §05「所以主题实验室里有三种预览」和上一句引语之间因果偏弱 → 可选做法：保留开头和 §01 的两个，§03 改「同一篇文章排六遍，只能看出颜色不同，于是……」，§05 直接写「主题实验室里有三种预览」。
- [全文数字] 「六个系列」「三种配色」「十八种配色」用汉字，「24 个组件」「5 行左右」用阿拉伯数字 → 同一篇内建议统一；常见做法是“计数小于十的用汉字、规格参数用阿拉伯数字”，定一条规则全文照办即可。
- [§04 第2段]「贴不贴边，要看这个系列想给读者什么感觉」→ 稍虚，按叶圣陶“念几遍”的办法读，会想追问“什么感觉” → 可选做法：落到一个具体感受，如“白皮想让人慢慢看图，墨刊想让人一口气扫完”。
- [§05 第2段] 引语格式的「一个组件值得出现，不是因为它好看……」→ 这是作者自己的话，但用引用块排出来，读者可能以为在引别人 → 无需改字；如果主题里有“金句”样式，可以换成那个，避免被当成引语。
- [§01 标题]「先说一句：这些主题都是自己画的」→ 按津瑟“一篇只做一件事”，这一节在讲原创与版权，可以考虑缩成 §02 前的一两句，或挪到文末，让读者更快看到“怎么选”。属于结构取舍，不改也成立。

## 没问题的部分
- **主线清楚**：“按文章类型选，不按颜色选”是读者能复述的一句话，§02 表格的三列（系列 / 适合写什么 / 一眼认出它）设计得好，一张表就把选择问题讲完了。
- **数据一致**：摘要、导语、表格、正文里的系列数、配色数、参数前后对得上，§04 的“松”“紧”与表中数字吻合。
- **语言干净**：短句多、口语自然，几乎没有空话套话，「白皮故意放得很松，墨刊故意收得很紧」这种句子具体又好记，保有作者自己的声音。
- **有一手细节**：一个个具体的组件、参数、检查项（「换主题前后，文字一个不少」「改稿时更新原草稿，不新建一篇」），读者能看出是真做过的。
- **结尾互动相关**：「你下一篇文章，最想用哪个系列来排？」紧扣全文，不是通用套话。
- **诚实的限制说明**：「如果你看到的是竖着排开的图片，说明被过滤了」把可能的缺陷提前讲清，读者会更信任。
