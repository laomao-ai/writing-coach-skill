# 风格档案（可选）

想让写出来、改出来的稿子更像你，就建一份风格档案。成稿和打磨都会读它。

## 怎么建
给 2–3 篇你满意的旧文章，或者直接描述。提炼成下面几项，存成 style/你的名字.md：

```
# 风格档案：作者名
- 人称与身份：我 / 我们；以什么身份说话
- 句子：长短、节奏、爱不爱用短句收尾
- 口头表达：常用的词、说法（照原样记）
- 语气：确定程度（“我觉得”“可能”怎么用）、幽默程度
- 结构习惯：开头怎么起、结尾怎么收、小标题风格
- 不要：你讨厌的写法
```

## 怎么用
- 成稿：按档案写；档案和文体习惯冲突时，以档案为准。
- 打磨：档案里记下的口头表达和语气不改。
- 档案只记风格，不记观点；每篇的观点以当篇为准。
