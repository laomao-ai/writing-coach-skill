# 检查清单：逻辑、事实、错别字

体检各关用到的清单。AI 腔单列在 ai-tone.md。


## 逻辑
### 第 1 组：立意
- 主题能否一句话说清？读者是谁？
- 读完要读者相信什么、做什么？结尾兑现了开头的承诺吗？
- 有没有两个互相竞争的主题？

### 第 2 组：结构与论证
- 结论先行，或有意设悬念并最终回收？
- 每个论点有论据吗？论据能支持论点吗（相关≠因果）？
- 有无跳步、循环论证、以偏概全、幸存者偏差、诉诸权威、因果倒置？
- 同级论点是否 MECE？有没有凑数的一条？
- “所以”“因此”前后真的有因果吗？

### 第 3 组：读者
- 开头 3 句内，读者知道这篇和自己有关吗？
- 术语、缩写第一次出现时解释了吗（知识的诅咒）？
- 读完读者能复述哪一句？能做哪一件事？

## 事实核查
1. **抽取**：数字、日期、人名、机构、引语、研究结论、因果断言。
2. **分类**：
   - 个人经历 / 自家数据（“我去年……”“我们后台……”）：不要求外部出处，只提醒作者自己核对。
   - 公共事实：需要来源。
   - 观点（带“我觉得”“可能”）：不是事实，不核查，但看有没有论据。
3. **逐条记录**：断言 / 类型 / 来源 / 状态。
4. **状态只有三种**：
   - 已核实：给出一手来源和日期。
   - 待核实：写清缺什么（例如“没有研究名称、机构、年份”）。
   - 疑似错误：必须写出依据（与已核实来源矛盾、时代不符、前后数字矛盾）。仅凭“没听说过”不能判疑似错误。
5. **引语**：必须能找到原出处（篇名、收录集或发言场合）；找不到就建议删除或改为作者自己的话。名人名言是虚构重灾区，默认待核实。
6. **一手优先**：原文、官方公告、财报、论文、工商登记信息；公众号转载、百科不算一手。
7. **不顺手补**：找不到就留空，不替作者补数字、补出处。

## 素材佐证：接搜索引擎
本 skill 不绑定某一引擎，按环境已有的工具选用：Tavily、Exa、百度搜索、博查、AnySearch、企查查（企业信息）等。
流程：断言 → 提炼检索词 → 至少两个独立来源交叉 → 记录来源与日期 → 以“事实+出处”的形式回写给作者。
禁止：检索不到就编；用二手转载冒充一手。

## 错别字与规范
### 高频混淆
- 的 / 地 / 得：定语用“的”，状语用“地”，补语用“得”。
- 做 / 作：具体动作多用“做”（做事、做饭），抽象、书面多用“作”（作为、作用、作出决定）。
- 在 / 再：“再”表重复或将来（再试一次），“在”表位置或进行（在做）。
- 那 / 哪：疑问用“哪”。
- 账号 / 帐号：现行规范用“账号”。
- 常见形近：截止 / 截至（到某时间为止用“截至”）、副 / 付（“一副眼镜”）、即 / 既。

### 标点
- 中文正文用全角标点；英文、数字、代码内部用半角。
- 引号层级：先用“”，内层用‘’。
- 省略号用“……”（两个），破折号用“——”（两个）。
- 书名、篇名、文件名：书名号《》只用于书、文章、作品等，不用于产品名或品牌名。

### 数字与单位
- 同一篇内数字写法统一（阿拉伯数字或汉字二选一）。
- 百分号、单位与数字之间不加空格；中英文之间是否加空格，全文统一即可。

### 一致性
- 人名、产品名、机构名全文写法一致（大小写、简称、译名）。
- 前后出现的同一数字一致（摘要与正文、表格与正文）。

依据：国家标准《标点符号用法》（GB/T 15834—2011）、《出版物上数字用法》（GB/T 15835—2011）；具体条款以标准原文为准。
