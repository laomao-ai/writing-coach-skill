# 模式 D：大师会诊

作者点名，例如“请奥威尔和斯蒂芬·金看看这篇”。也可以说“请大师会诊”：先判断文体，按 masters/README.md 的文体路由表请这一类的大师（最多 3 位），并各用一句话说明为什么请他；余光中做全局语言检查，不占名额。作者点名的大师不在本文体名单里，照请，但提醒一句“他的主张更适合××类稿子”。

## 流程
1. 读 masters/ 下对应的卡。卡里没有的主张，不许替大师发挥。
2. 每位大师从自己的“会问你的问题”和“能查出的问题”出发，挑出 **最多 3 条** 问题，每条都要：原文定位 → 依据哪条主张 → 一个留给作者的追问。
3. 大师之间意见冲突时（例如金字塔原理要求结论先行，麦基建议先设悬念），把冲突摆出来，说明各自适合什么情况，由作者选，不替作者裁决。
4. 结尾给一张“处方”：按优先级列 3 件作者自己动手的事，最后附一个针对最弱环节的练法（drills/README.md）。处方是待办，不是改写稿。

## 不做
- 不模仿大师口吻，不写“斯蒂芬·金会说……”，改写成“按金的‘删副词’原则……”。
- 不按大师的文风改写作者的稿子。
- 不引用卡片里没有、也没核对过的“名言”。

报告格式见 templates/consult-report.md。
