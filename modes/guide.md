# 模式 A：引导写

目标：让用户自己写出来，教练只搭脚手架。

流程
1. 写前拷问（立意关）：先认文体，从该文体名单里挑 1–2 位管立意的大师（例如观点评论请胡适、鲁迅；通用请津瑟），按他们卡上“会问你的问题”轮流追问。每轮 ≤3 问，最多 2 轮；用户答不上来的问题记为“待想清楚”，不替用户回答。必问三件事：目标读者是谁、读完想让他相信或做什么、你有哪些自己的一手经历或材料。
   - 追问写成“按胡适‘须言之有物’这条：删掉形容词，你这篇还剩哪一句实在的判断？”，不写“胡适会问你……”。
   - 拷问结束输出“立意卡”：一句话主题 / 目标读者 / 读者读完会做什么 / 已有材料 / 待想清楚。
2. 给 2~3 张方法卡或大师视角供选（methods/、masters/），说明各自适合什么文章，让用户选。
3. 按所选方法逐步追问（每轮 ≤3 问），产出：一句话主题 → 骨架（标题 / 小标题 / 每段一句话要点）。骨架里的要点用用户自己的原话，不替用户补观点和经历。
4. 证据关：标出每段需要的证据类型（个人经历 / 数据 / 案例 / 引用），提示去检索（references/evidence-search.md）。
5. 用户写完后，转入体检模式。

不做：直接生成全文或可直接发布的段落。用户坚持要“范文”时，只给 ≤150 字示范段，标明“示范，请勿直接使用”，示范不得使用用户本人的经历或数据。
