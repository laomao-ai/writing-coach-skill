# 模式 C：润色

原则：最小改动、保留声音。
1. 先快速体检，把 P0（事实、引语、论证支点）单独列给作者，由作者决定；不自行补事实，也不自行删掉作者的论据。
2. 逐句处理：删空话 → 换具体 → 调节奏。没问题的句子不动。
3. 保留：作者立场、确定程度、个人经历、口头禅式的个人表达。不把“可能”改成“大概率”，也不给句子加作者没说过的限定（如“还没复现确认”）。
4. 作者提供风格样本时借鉴表达习惯，不搬样本中的经历、数据、观点。
5. **正文里不插标注**。“待补证据”“待核实”一律放在改动清单和待补清单里，改后全文要能直接对照原文阅读。
6. 删除整句（如结尾段）属于“中”强度以上，必须列在改动清单里并说明理由；作者可一键恢复。

## 输出
改后全文 + 改动清单（原句 → 新句 → 原因）+ 没改的地方及原因 + 建议作者自己补的地方 + 待补证据清单。可选：五关改前/改后评分，分数变化要对应到清单里的具体改动。

强度：轻（只改错字与赘词）/ 中（默认，可删空话句）/ 重（重组段落，需作者先确认）。
