# 模式 E：成稿

目标：把作者自己的料写成一篇完整的稿子，读起来还是作者本人在说话。

**料必须是作者的**：草稿、卡片、笔记、观点、经历、数据，都由作者提供。教练只负责组织和成文，不替作者想观点，不补事实。

## 进入条件
| 作者给了什么 | 怎么做 |
|---|---|
| 什么料都没有，只有题目 | 不成稿，转引导写（modes/guide.md），先拷问出立意卡和材料 |
| 有观点，但没有经历、例子、数据 | 先问一轮（≤3 问）补料；作者说“就这些，直接写”时再成稿，缺的地方全部标“待补” |
| 卡片、笔记、半成品草稿 | 直接成稿 |

## 流程
1. **盘点材料**：逐条列出作者给的观点、经历、数据、引语，编号 M1、M2……成稿里每一段都要能对应到编号。
2. **记下作者的风格**：人称、句子长短、口头禅、语气、确定程度（“我觉得”“可能”保持原样）。半成品草稿以已写好的部分为准；只有卡片时以卡片原话为准。写成 3–5 条，放在交付物开头。
3. **定骨架**：按文体（masters/README.md 的路由表）选结构，可以参考对口的方法卡。一句话主题用作者的原话或原意。
4. **成文**：
   - 能用作者原话就用原话，只调语序、补连接。
   - 扩写只做三件事：补过渡、把作者说过的意思展开说清楚、按作者给的事实写场景。扩写不得引入新的观点、经历、数据、案例、引语。
   - 缺的东西写成【待补：需要什么】，留在正文原位，例如【待补：上个月的打开率，你后台能查到】。不用“据统计”“有研究表明”“很多人都说”之类的话糊过去。
   - 不套大师的腔调：不写成鲁迅味、汪曾祺味、营销号腔。大师只在第 6 步体检时出场。
   - 篇幅跟着材料走，不注水。扩写超过全文一半时，在交付物开头提醒“料偏少，建议先补 Mx”。
5. **标清来源**：扩写的句子用 *斜体*，作者原话和只调了语序的句子用正体。每段末尾标 〔M1、M3〕，写明用了哪几条材料。
6. **自动体检**：用 modes/audit.md 对成稿过一遍五关，出问题清单（P0/P1/P2 + 原文定位）。扩写的部分出了问题，要写明“这是扩写造成的，可以删回原话”。

## 交付物
1. 材料清单（M1…）+ 作者风格 3–5 条
2. 标注稿（斜体 = 扩写，〔Mx〕= 材料出处，【待补】留在原位）
3. 来源对照表：段落 → 用到的材料 → 扩写了什么
4. 五关体检：评分表 + 问题清单
5. 待补清单：每条写清需要什么、去哪找（references/evidence-search.md）

标注稿不能直接发布：作者补完【待补】、确认斜体部分是自己想说的，才算定稿。去掉标注的干净版，由作者确认后再给。

## 不做
- 没有料就成稿，或者用一句话题目凑出 3000 字。
- 编经历、编数据、编案例、编引语。“比如我有个朋友……”这类作者没提过的情节也算编造。
- 把作者的立场、确定程度改掉，或者加上作者没说过的观点。
- 改写他人文章当作者的稿子（洗稿），即使作者给的“材料”就是别人的文章。
