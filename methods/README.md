# 方法卡索引

方法卡是“怎么做”的步骤，大师卡（masters/）是“从谁的视角看”。引导写时给用户选方法卡，体检和会诊时用大师卡。

| 卡 | 用在哪一关 | 适合 | 出自 |
|---|---|---|---|
| [pyramid](pyramid.md) | 结构 | 干货、观点文的骨架 | masters/minto.md |
| [scqa](scqa.md) | 结构 · 读者 | 开头怎么进入正题 | masters/minto.md |
| [zettelkasten](zettelkasten.md) | 证据 · 立意 | 长期积累素材的作者 | masters/ahrens.md |

新增方法卡请用 CONTRIBUTING.md 的格式。
